# Screenshot Checklist

Add sanitized screenshots here before submitting the contribution.

Recommended screenshots:

- ACE dashboard showing the Product Usage milestone.
- GitHub repository home page.
- Oracle APEX App Builder application list or app overview.
- Oracle APEX Page Designer with the suggestion region selected.
- Dynamic Content region source or PL/SQL call.
- Running APEX dashboard with `Sugerencias IA`.
- SQLcl, SQL Developer, or SQL Workshop showing sanitized validation.
- Scheduler job or package compilation evidence.

## Sanitization Rules

- Hide passwords and tokens.
- Hide private endpoints when not required.
- Hide customer names and fiscal data.
- Replace real users with demo users when possible.
- Avoid showing raw production records.
