# Oracle APEX Product Usage Portfolio

This repository is my public Oracle APEX product usage portfolio. I use it to
share practical work, sanitized examples, screenshots, and notes from real
Oracle APEX learning and implementation experiences.

My main focus is Oracle APEX, supported by Oracle Database, PL/SQL, SQL, SQLcl
and ORDS. Each contribution is written so another APEX developer can understand
what was built, why it matters, and what Oracle product features were used.

## What I Include

- A short explanation of the business or technical scenario.
- Screenshots of Oracle APEX, Oracle Database, SQLcl, SQL Developer, or GitHub.
- Sanitized SQL and PL/SQL examples.
- APEX configuration notes when they help explain the implementation.
- Clear notes about what I learned.

## Quality Rules

- Each contribution must be created after the relevant ACE Apprentice milestone
  acceptance date.
- The Oracle products used must be clear.
- Screenshots must be readable and sanitized.
- Code examples must not include passwords, tokens, private endpoints, customer
  data, fiscal documents, or personal data.
- External tools or services must be described as external. The Oracle product
  usage must remain central.
