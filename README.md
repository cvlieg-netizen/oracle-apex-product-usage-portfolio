- Oracle APEX

- PL/SQL

## Quality Rules

- Each contribution must be created after the relevant ACE Apprentice milestone
  acceptance date.
- Each contribution must explain the Oracle product used.
- Each contribution must include what was built, what was learned, and what
  evidence is submitted.
- Screenshots and videos must not expose passwords, tokens, private endpoints,
  customer data, fiscal documents, or personal data.
- External tools or services must be described as external. The Oracle product
  usage must remain central and clear.

## Recommended Evidence for Each Contribution

- GitHub documentation
- Screenshots of Oracle APEX Builder or Page Designer
- Screenshots of the running APEX application
- SQLcl, SQL Developer, or SQL Workshop validation evidence
- Short video walkthrough
- Sanitized SQL and PL/SQL examples
- Notes about lessons learned
